# Notes From a Passive-Aggressive Fridge

The one-line note a smart fridge leaves for its owner:

> The yogurt expired Tuesday. I watched you sniff it and put it back. I said nothing. Until now.

94 characters. The setup sounds like a flat status report; the turn reveals the fridge was watching the owner sniff the expired yogurt and put it back; the sting is that the fridge held the grudge in silence — until now.

## How to run

```sh
python3 main.py
```

This writes the note verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
